ഏത് വിൻഡോയുടെയും ആപ്പിന്റെയും സ്ക്രീൻഷോട്ട്

വെബ് പേജുകൾ മാത്രമല്ല: ബ്രൗസറിന്റെ സ്വന്തം ഷെയർ പിക്കർ ഉപയോഗിച്ച് മറ്റൊരു ബ്രൗസർ വിൻഡോയോ ഡെസ്ക്ടോപ്പ് ആപ്പോ നിങ്ങൾ ഇപ്പോൾ നോക്കാത്ത ഒരു ടാബോ ക്യാപ്ചർ ചെയ്യാം.

Chrome-ൽ ചേർക്കൂ, സൗജന്യമാണ്

എങ്ങനെ ചെയ്യാം

  1. Vynko ഐക്കണിൽ ക്ലിക്ക് ചെയ്യുക, എന്നിട്ട് സ്ക്രീനിൽ എവിടെയും എന്നതിൽ വിൻഡോ അല്ലെങ്കിൽ സ്ക്രീൻ തിരഞ്ഞെടുക്കുക.
  2. ബ്രൗസറിന്റെ ഷെയറിംഗ് ബോക്സിൽ വിൻഡോ തിരഞ്ഞെടുത്ത് പങ്കിടുക അമർത്തുക.
  3. സ്ക്രീൻഷോട്ട് എഡിറ്ററിൽ തുറക്കും, അടയാളപ്പെടുത്താനും സേവ് ചെയ്യാനും തയ്യാർ.

അറിഞ്ഞിരിക്കാൻ

  • വിൻഡോകളുടെ ലിസ്റ്റ് നിങ്ങളുടെ ബ്രൗസറിൽ നിന്നും ഓപ്പറേറ്റിംഗ് സിസ്റ്റത്തിൽ നിന്നുമാണ് വരുന്നത്.
  • macOS-ൽ ആദ്യ തവണ System Settings-ൽ Chrome-ന് Screen Recording അനുമതി നൽകണം.
  • ഒന്നും ഷെയർ ചെയ്യുകയോ അപ്‌ലോഡ് ചെയ്യുകയോ ഇല്ല: ഫ്രെയിം നിങ്ങളുടെ ഡിവൈസിൽ തന്നെയാണ് ക്യാപ്ചർ ചെയ്യുന്നത്.

ചോദ്യങ്ങൾ

ബ്രൗസർ അല്ലാത്ത ഒരു ആപ്പിന്റെ സ്ക്രീൻഷോട്ട് എടുക്കാമോ?

ഉവ്വ്, Word, Excel, Figma, Terminal പോലെ നിങ്ങളുടെ സിസ്റ്റം Chrome-ന് ഷെയർ ചെയ്യാൻ അനുവദിക്കുന്ന ഏത് വിൻഡോയും.

macOS എന്തുകൊണ്ട് അനുമതി ചോദിക്കുന്നു?

Chrome ഉൾപ്പെടെ, വിൻഡോകൾ ക്യാപ്ചർ ചെയ്യുന്ന ഏത് ആപ്പിനും macOS-ൽ Screen Recording അനുമതി വേണം.

ചിത്രം എവിടെയെങ്കിലും അപ്‌ലോഡ് ചെയ്യുമോ?

ഇല്ല. അത് നിങ്ങളുടെ ഡിവൈസിൽ തന്നെ ഇരിക്കും.

  • ഒറ്റ ക്ലിക്കിൽ Chrome ടാബിന്റെ സ്ക്രീൻഷോട്ട്നിലവിലെ ടാബിൽ നിങ്ങൾ കാണുന്നത് അതേപടി, ബ്രൗസർ ബാറുകൾ ഇല്ലാതെ ക്യാപ്ചർ ചെയ്യുക. എന്നിട്ട് അതിൽ അടയാളപ്പെടുത്തുക, സ്വകാര്യ വിവരങ്ങൾ മങ്ങിക്കുക, സേവ് ചെയ്യുകയോ കോപ്പി ചെയ്യുകയോ ചെയ്യുക.
