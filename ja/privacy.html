プライバシーポリシー

概要

Vynko は個人データを一切収集、保存、販売、共有しません。アカウント、サーバー、アクセス解析、広告、Cookie、トラッキングはいずれもありません。

このプライバシーポリシーは、すべてのバージョンの Vynko に適用されます。

端末内に保存されるもの

  • 形式、テーマ、エディターの色、ファイル名のパターン、ダウンロード先フォルダーなどの設定 (ブラウザー拡張機能のストレージに保存)。
  • 録画中のデータ。クラッシュ後に復元できるよう、ブラウザーのローカルデータベースに保存されます。以前の録画が保存された後、新しい録画を開始した時点で削除されます。
  • エディターを開いている間のスクリーンショット、およびダウンロードを選んだファイル。

これらはすべてお使いのブラウザーのプロファイル内に保存されます。Vynko をアンインストールすると、ダウンロードしたファイルを除き、これらは削除されます。

権限

  • activeTab, scripting: 選択したタブでのみ動作し、そのタブのキャプチャ、範囲選択、キャプチャ前のカウントダウン、ページ上のエディターの表示を行います。「個人情報をぼかす」を提供するため、Vynko はキャプチャの時点でそのページのテキストからメールアドレスと電話番号を探します。この確認はお使いのブラウザー内で行われ、何も保存も送信もされません。
  • tabCapture, offscreen: 録画を開始したときにタブを録画します。
  • downloads: ファイルを保存します。
  • storage: 設定を記憶します。
  • マイクとカメラ: マイクまたは Web カメラをオンにした場合に限り、ブラウザーから一度だけ許可を求められます。声と Web カメラの映像は、保存する録画にのみ使われます。Vynko がそれらをほかの場所に送信したり保存したりすることは一切ありません。
  • desktopCapture: 「選択」を選んだときに、ブラウザー標準の共有対象を選ぶ画面を開き、任意のタブ、ウィンドウ、または画面全体を録画できるようにします。録画されるのは、そこで選んだものだけです。

ネットワーク

Vynko はネットワーク通信を一切行わず、そのコンテンツ セキュリティ ポリシーではローカルの blob URL と data URL への接続のみが許可されています。フォントとアイコンは拡張機能に組み込まれています。拡張機能自体がサーバーに接続することはありません。新しいタブで Web ページを開くリンクは 3 つあります: PayPal のリンクとレビューのリンク (いずれもクリックした場合のみ)、そして Vynko をアンインストールしたときにブラウザーが開く、Google Forms 上の任意回答の短いフィードバックフォームです。フォームのアドレスには Vynko のバージョン番号のみが含まれ、それ以外の情報は含まれません。これらのページでは、PayPal および Google それぞれのプライバシーポリシーが適用されます。

あなたの権利

欧州の GDPR や UK GDPR、カリフォルニア州の CCPA などのプライバシー法は、企業が保有するあなたに関するデータについて、あなたに権利を与えています。私はあなたに関するデータを一切保有していないため、開示、訂正、削除、販売の対象となるものはありません。Vynko のローカルデータを消去するには、アンインストールするか、ブラウザーで拡張機能のデータを消去してください。

Vynko は子どもを対象としたものではなく、子どもを含め、どなたからも情報を収集しません。
