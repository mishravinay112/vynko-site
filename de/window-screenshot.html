Screenshot von jedem Fenster oder Programm

Nicht nur Webseiten: Nimm ein anderes Browserfenster, ein Desktop-Programm oder einen einzelnen Tab auf, den du gerade nicht ansiehst, über die Freigabeauswahl deines Browsers.

Zu Chrome hinzufügen, kostenlos

So geht's

  1. Klick auf das Vynko-Symbol und wähle unter Überall auf deinem Bildschirm die Option Fenster oder Bildschirm.
  2. Wähl das Fenster im Freigabedialog deines Browsers aus und klick auf Teilen.
  3. Der Screenshot öffnet sich im Editor, bereit zum Markieren und Speichern.

Gut zu wissen

  • Die Liste der Fenster kommt von deinem Browser und Betriebssystem.
  • Unter macOS braucht Chrome beim ersten Mal die Berechtigung für Bildschirmaufnahme in den Systemeinstellungen.
  • Nichts wird geteilt oder hochgeladen: Das Bild wird auf deinem Gerät aufgenommen.

Fragen

Kann ich einen Screenshot von einem Programm machen, das kein Browser ist?

Ja, von jedem Fenster, das dein System für Chrome freigibt, zum Beispiel Word, Excel, Figma oder Terminal.

Warum fragt macOS nach einer Berechtigung?

macOS verlangt die Berechtigung für Bildschirmaufnahme bei jedem Programm, das Fenster erfasst, auch bei Chrome.

Wird das Bild irgendwo hochgeladen?

Nein. Es bleibt auf deinem Gerät.
